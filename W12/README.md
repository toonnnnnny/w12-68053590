# 68053590 กุลธิดา กำเหนิด — CSI205

## วิธีเปิดโปรเจกต์
1. แตกไฟล์ ZIP และเปิดโฟลเดอร์นี้ใน VS Code
2. เปิด Terminal แล้วพิมพ์ `npm install`
3. พิมพ์ `npm run dev`
4. เปิด http://localhost:3000

ต้องติดตั้ง Node.js 20.9 ขึ้นไป

หน้า Home: ประวัติ รูป และช่องทางติดต่อ
หน้า Calculator: งาน W03 ต้นฉบับ (HTML/CSS/JS)
หน้า Animation: ดัดแปลงงาน W04 ให้ใช้กับ Next.js และแก้ปุ่มหยุด/คีย์บอร์ด
หน้า Todos: งานเดิมของโปรเจกต์

ไม่มี node_modules, .next และ .git ใน ZIP; สร้างไฟล์สำหรับรันใหม่ด้วยคำสั่งด้านบน
